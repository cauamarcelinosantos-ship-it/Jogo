  OPÇÃO 1: Um comando (Recomendado) ⭐

  $ cd react-app && npm install && npm run dev

  → Abra: http://localhost:3000

═══════════════════════════════════════════════════════════════════════════════
  🆘 PROBLEMAS COMUNS
═══════════════════════════════════════════════════════════════════════════════

  ❌ "Command not found: bash"
  → Você está no Windows
  → Use: START.bat (duplo-clique)
  → Ou: node start.js

  ❌ "Python not found"
  → Instale Python: https://python.org
  → Ou use: node start.js

  ❌ "Node.js not found"
  → Instale Node.js: https://nodejs.org
  → Vem com npm incluído

  ❌ "Port already in use"
  → Outra aplicação usa a porta
  → Mude manualmente (exemplo 8080)
  → python3 -m http.server 8080

  ❌ "Navegador não abre"
  → Abra manualmente:
  → http://localhost:8000 (Vanilla)
  → http://localhost:3000 (React)
