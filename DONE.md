🚀 COMO USAR

VANILLA JAVASCRIPT (Recomendado para teste imediato)
───────────────────────────────────────────────────
1. Abra: index.html em qualquer navegador
   OR
2. Execute:
   $ python -m http.server 8000
   Acesse: http://localhost:8000

Não há instalação necessária! ⚡

REACT (Recomendado para desenvolvimento)
──────────────────────────────────────────
1. Entre no diretório:
   $ cd react-app

2. Instale dependências:
   $ npm install

3. Inicie o servidor de desenvolvimento:
   $ npm run dev

4. Abra automaticamente:
   http://localhost:3000
