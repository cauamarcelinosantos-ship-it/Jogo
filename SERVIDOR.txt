  ⚡ FORMA MAIS RÁPIDA: Um Comando!
═══════════════════════════════════════════════════════════════════════════════

  $ node server.js

  ✅ Servidor inicia na porta 8000
  ✅ Navegador abre automaticamente
  ✅ Pronto para jogar em segundos!


═══════════════════════════════════════════════════════════════════════════════
  🔧 OPÇÕES DE PORTA
═══════════════════════════════════════════════════════════════════════════════

  PORTA PADRÃO (8000):
  $ node server.js

  PORTA CUSTOMIZADA (exemplo 3000):
  $ PORT=3000 node server.js

  PORTA CUSTOMIZADA (Windows):
  > set PORT=3000 && node server.js

  PORTA CUSTOMIZADA (PowerShell Windows):
  > $env:PORT=3000; node server.js


═══════════════════════════════════════════════════════════════════════════════
  📊 PORTAS DISPONÍVEIS
═══════════════════════════════════════════════════════════════════════════════

  Recomendado: 8000, 3000, 5000, 8080, 9000
  
  Se receber erro "EADDRINUSE":
  → Porta já está em uso
  → Tente outra porta: PORT=3000 node server.js


═══════════════════════════════════════════════════════════════════════════════
  🎮 COMO JOGAR
═══════════════════════════════════════════════════════════════════════════════

  1. Execute:
     $ node server.js

  2. Navegador abre automaticamente em:
     http://127.0.0.1:8000

  3. Faça login (Google ou Anônimo)

  4. Crie novo jogo

  5. Explore, colete, combata, suba de nível!

═══════════════════════════════════════════════════════════════════════════════
  🌐 ACESSAR EM OUTRO COMPUTADOR
═══════════════════════════════════════════════════════════════════════════════

  Padrão (apenas local):
  http://127.0.0.1:8000
  http://localhost:8000

  De outro computador (precisa mudar código):
  http://SEU_IP:8000

  const HOST = '0.0.0.0';  // ao invés de '127.0.0.1'

═══════════════════════════════════════════════════════════════════════════════
  🆘 RESOLUÇÃO DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════════════

  ❌ "listen EADDRINUSE: address already in use :::8000"
  → Porta 8000 já está em uso
  → Use: PORT=3000 node server.js

  ❌ "Cannot find module"
  → Erro de Node.js
  → Certifique-se que está no diretório correto
  → Node.js está instalado: node --version

  ❌ "ENOENT: no such file or directory"
  → Arquivo não encontrado
  → Verifique que index.html existe

  ❌ "Permission denied"
  → Problema de permissões
  → Use: sudo node server.js (se necessário)
